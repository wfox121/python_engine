# Face Detection
A script that detects faces from the camera in real-time using OpenCV and Haar Cascades.

### Features
- Real-time face detection from webcam
- Face count overlay display
- Error handling for camera and cascade loading
- Proper resource cleanup

### Prerequisites
```bash
pip install -r requirements.txt
```

### How to run the script
```bash
python face-detection.py
```

### Controls
- Press 'q' to quit the application
